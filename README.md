# Releases

Installers for the apps in the suite, and `catalog.json`, the list [Hangar](https://github.com/RohithOrg/hangar) reads to install and update them.

Get **Hangar** from the latest `hangar-v*` release below, then install everything else from inside it.

Every installer here is signed; Hangar refuses any file whose signature doesn't match. This repository holds no source code.
